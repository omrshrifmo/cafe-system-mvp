# Binaries Directory (Mazaj OS)

This folder contains third-party standalone binaries required for desktop packaging:

1. **Cloudflare Tunnel Client (`cloudflared`)**:
   - Download the official Windows 64-bit binary from Cloudflare:
     https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe
   - Save it in this directory as:
     `bin/cloudflared.exe` (or `bin/cloudflared-windows-amd64.exe`)
   - For Linux development/testing:
     `bin/cloudflared` (chmod +x)
